# Ruta de aprendizaje en análisis de datos

Bitácora de plan de aprendizaje para reforzar y optimizar conocimientos en análisis de datos.
El conomiento se comparte, este repositorio se mantiene público para apoyar a todo el que busque obtener un breve manual del funcionamiento con las herramientas más utilizadas en las profesiones de data.

## Objetivo

Reforzar las herramientas de uso actual, aprender nuevas herramientas y lenguajes, y construir distintos proyectos de portafolio.
